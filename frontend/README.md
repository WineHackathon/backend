# WineHackathon Web Frontend (`frontend`)

Single-Page Web Application for label scanning, catalog exploration, and AI Sommelier conversation.

## Features
- **Label Scanner**: Camera upload, real-time image preview, and sub-second recognition via Gateway.
- **Wine Card**: Displays category, grape varieties, winery, tasting notes, and Roskachestvo rating badge.
- **AI Sommelier Chat**: Interactive chat with contextual wine knowledge and food pairings.
- **Yandex ID OAuth 2.0 Button**: 1-click authorization via Yandex ID.

## Development
```bash
npm install
npm run dev
```
