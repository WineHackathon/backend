# База знаний и контекст проекта: Сканер вин «Своё Вино»

Данная папка содержит структурированную документацию, хронологию разработки, архитектурные решения и контекст проекта для хакатона **«Лидеры цифровой трансформации 2026»** (Задача №202 от Россельхозбанка).

---

## 📑 Структура базы знаний

1. **[`01_PROJECT_OVERVIEW.md`](./01_PROJECT_OVERVIEW.md)**
   - Паспорт задачи хакатона, партнер (РСХБ), цели, целевая аудитория, требования к сервису и продуктовая ценность.
2. **[`02_ARCHITECTURE_AND_SYSTEM_DESIGN.md`](./02_ARCHITECTURE_AND_SYSTEM_DESIGN.md)**
   - Архитектурная топология 10 микросервисов, Bounded Contexts, выбор брокера (Redis Streams RPC), хранилище S3 (MinIO) и модель данных.
3. **[`03_WORKFLOW_AND_CHANGELOG.md`](./03_WORKFLOW_AND_CHANGELOG.md)**
   - Хронологический лог выполненных работ: какие фичи добавлены на каждом этапе, какие коммиты запушены.
4. **[`04_API_AND_INTEGRATIONS_MAP.md`](./04_API_AND_INTEGRATIONS_MAP.md)**
   - Карта всех эндпоинтов шлюза (`:8080`) и внутренних микросервисов, включая чекер `/v1/eval/predict`, Яндекс ID OAuth, каталог и сомелье.
5. **[`05_EVALUATION_HARNESS_GUIDE.md`](./05_EVALUATION_HARNESS_GUIDE.md)**
   - Руководство по запуску официального чекера хакатона `participant_test.sh`, оптимизации задержки и проверке точности.
6. **[`06_NEXT_STEPS_AND_ROADMAP.md`](./06_NEXT_STEPS_AND_ROADMAP.md)**
   - Текущий статус, пошаговый план запуска полного стенда, сидинг каталога вин и подготовка к защите перед жюри.
